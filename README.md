# The VARC Vault

Original CAT VARC practice portal: 50 argument questions (inference, assumption, strengthen, weaken), 25 CAT-length passages built from verified national and international events of May-July 2026 (each with 3 questions), and 60 CAT tones with synonyms, meanings and examples. Every question carries an answer and a full explanation.

## Run

```
npm install
npm run dev
```

## Build

```
npm run build   # type-checks with tsc, then bundles to dist/
npm run preview
```

Hash-based routing, so the built site works on static hosts such as GitHub Pages without server rewrites.

Content is original CAT-style practice written for study, not past CAT questions. Event passages cite dated news sources in each passage's source line.
